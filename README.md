# DUNGEON UNITY

## Tecnologías utilizadas

* Unity
* C#
* Blender
* Git
* GitHub

## Objetivos principales

* Diseñar sistemas desacoplados y reutilizables.
* Mejorar la arquitectura general del proyecto.

* Crear una estructura escalable para futuras funcionalidades.

* Arquitectura de software en Unity.

* Organización de proyectos grandes.
* Flujo de trabajo Blender → Unity.
* Diseño de sistemas reutilizables.
